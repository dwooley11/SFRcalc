Analyze a Zillow listing
in one tap.

Add the ⚡ SFRcalc button to your browser once. Then tap it on any Zillow listing and this page opens with price, sq ft, tax history and Rent Zestimate loaded and the model already run.

  1. Show your bookmarks bar: ⌘/Ctrl + Shift + B.
  2. Drag this button onto the bar:
    ⚡ SFRcalc
    Works in Chrome, Edge, Safari, Firefox and Brave.
  3. Open any listing on zillow.com and click ⚡ SFRcalc in the bar.
Option A · Safari bookmark (2 min setup)
  2. In Safari, on any page, tap Share → Add Bookmark. Name it SFRcalc → Save.
  3. Tap the Bookmarks icon → Edit → tap SFRcalc. Clear the address line, paste the copied code → Done.
  4. To use: open the listing in Safari, tap the address bar, type SFRcalc, and tap the bookmark that appears.
Option B · Share Sheet shortcut
  2. Open Shortcuts → + → add the action Run JavaScript on Web Page. Replace its sample code with the copied code.
  3. Add the action Open URLs below it (it uses the JavaScript result automatically).
  4. Tap the ⓘ / settings → turn on Show in Share Sheet. Name it Send to SFRcalc.
  5. To use: on a listing in Safari, tap Share → Send to SFRcalc.

In the Zillow app? Tap Share → Open in Safari first. The button can't run inside the Zillow app.
